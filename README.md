## ⚙️ How to Configure

The first time you start the software, you must link your own accounts to enable the AI features.

1. Open the application.
2. Select the "Settings" tab in the left menu.
3. Select the "Providers" menu.
4. Enter your personal API keys for the services you want to use. You can obtain these keys from the websites of OpenAI, Anthropic, or Google.
5. Save your changes.
6. The dashboard will now display the available tools based on your active services. 

If you do not have an API key, the software offers a local mode that runs basic functions using your own computer hardware. Check the "Local Mode" toggle in the settings menu to activate this feature.

## 🛡 Security and Privacy

Your data stays on your machine unless you choose to send it to an AI provider. The application does not store your personal keys on any central server. All connections use encrypted channels to protect your information. 

## ❓ Frequently Asked Questions

**Does the software cost money to run?** 
The software is free to download. However, AI providers like OpenAI charge small fees based on how much data you process through their services.

**Can I run this without internet?** 
Some modules require an internet connection to reach the AI brains. You can download model files for offline use if you have enough storage space.

**Is it safe to give the software access to my files?**
You decide which folders the software can see. You can restrict access in the "Permissions" menu to keep sensitive documents private.

**How do I update the application?** 
If a new version comes out, a notification appears on the dashboard. Click the link in that notification to download the installer again. The new version will overwrite the old one without deleting your settings.

**Where do I see my logs?**
If you experience an error, click the "Support" icon. You will see a button to open your log folder. This text file contains details about what the software did last. You can share this text with others if you need help fixing a problem.
